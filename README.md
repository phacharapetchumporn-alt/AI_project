# Sign Language Gesture Recognition (Bi-LSTM + MediaPipe)

ระบบจดจำสัญลักษณ์มือและท่าทางการเคลื่อนไหวแบบเรียลไทม์ (Real-time Sign Language / Gesture Recognition System) โดยใช้เทคโนโลยีการตรวจจับข้อต่อมือ **MediaPipe Hands** ร่วมกับโมเดลโครงข่ายประสาทเทียม **Bidirectional LSTM (Bi-LSTM)** บนเฟรมเวิร์ก **PyTorch** และการแปลงโมเดลเพื่อใช้งานข้ามแพลตฟอร์มผ่าน **ONNX** และ **TensorFlow Lite (TFLite)**

---

## 📌 ขอบเขตของโปรเจกต์ (Project Scope)

โปรเจกต์นี้มีขอบเขตครอบคลุมตั้งแต่กระบวนการเก็บรวบรวมข้อมูลดิบ (Data Acquisition), การสร้างโมเดลปัญญาประดิษฐ์ (Deep Learning Model), การประเมินผล (Evaluation), ไปจนถึงการส่งออกโมเดล (Deployment Setup) และการทำนายผลสด (Real-time Inference) ดังรายละเอียดต่อไปนี้:

### 1. การดึงลักษณะเด่นและการเก็บข้อมูล (Feature Extraction & Data Collection)
* **การตรวจจับข้อต่อมือ (Hand Landmarks Detection):** ใช้ไลบรารี MediaPipe Hands ในการตรวจจับและติดตามจุดข้อต่อต่างๆ บนมือ โดยระบบจะประมวลผลข้อมูลของมือทั้งสองข้าง (ซ้ายและขวา) 
* **โครงสร้างของลักษณะเด่น (Feature Dimension):** แต่ละข้างจะดึงจุดเชื่อมต่อออกมาทั้งหมด 21 จุด ซึ่งแต่ละจุดจะมีพิกัด 3 มิติ (x, y, z) 
  * คำนวณเป็น: $21 \text{ จุด} \times 3 \text{ แกน} = 63$ พิกัดต่อข้าง
  * เมื่อรวมสองมือจะเท่ากับ $63 + 63 = 126$ พิกัดต่อเฟรม
* **การจัดเก็บข้อมูลการเคลื่อนไหว (Sequential Data):** บันทึกข้อมูลการเคลื่อนไหวเป็นลำดับเวลา (Temporal Sequence) โดยกำหนดให้ **1 ตัวอย่าง (Sample) ประกอบด้วย 30 เฟรมติดต่อกัน** (Sequence Length = 30) ซึ่งมีมิติข้อมูลเท่ากับ $30 \times 126$
* **คลาสและหมวดหมู่การทำนาย (Target Classes):** ปัจจุบันรองรับการจดจำทั้งหมด **6 คลาส** ได้แก่:
  * ท่าทางแทนสัญลักษณ์ตัวเลข: **`1`**, **`2`**, **`3`**, **`4`**, **`5`**
  * ท่าทางทั่วไป / ไม่มีสัญลักษณ์มือ (Background Class): **`Blank`**
* **การจัดเก็บไฟล์:** บันทึกข้อมูลดิบในรูปแบบไฟล์อาเรย์ NumPy (`.npy`) ลงในโฟลเดอร์แยกย่อยตามคลาสและวันเวลาที่ทำการเก็บ เพื่อความเป็นระเบียบและง่ายต่อการดึงไปใช้เทรนโมเดล

### 2. การสร้างและฝึกสอนโมเดล (Model Training)
* **โครงสร้างโมเดล Bi-LSTM:** พัฒนาโครงข่ายประสาทเทียมแบบ Bidirectional LSTM ด้วย PyTorch เพื่อเรียนรู้รูปแบบเชิงเวลา (Temporal Patterns) ของท่าทางสัญลักษณ์มือ โดยโมเดลมีเลเยอร์ LSTM แบบสองทิศทางจำนวน 2 ชั้น (Hidden Size = 128) เชื่อมต่อด้วย Fully Connected Layers และมี Dropout เพื่อป้องกันการเกิด Overfitting
* **การจัดการและจัดเตรียมข้อมูล:**
  * ใช้ `LabelEncoder` แปลงชื่อคลาสจากโฟลเดอร์ให้เป็นรหัสตัวเลข (และบันทึกไฟล์เป็น `label_encoder.pkl` สำหรับใช้ในขั้นตอนทำนายผล)
  * แบ่งชุดข้อมูลสำหรับฝึกสอน (Train Set) 80% และชุดข้อมูลสำหรับทดสอบ (Test Set) 20% แบบมีการรักษาสัดส่วนคลาสเท่าเดิม (Stratified Split)
* **กระบวนการฝึกสอนโมเดล:** ใช้ฟังก์ชันการวัดความสูญเสียแบบ `CrossEntropyLoss` และปรับแต่งน้ำหนักด้วย `Adam Optimizer` (Learning Rate = 0.001) เป็นจำนวน 50 รอบ (Epochs) และเก็บบันทึกน้ำหนักโมเดลที่ดีที่สุดไว้ในไฟล์ `action_model.pth`

### 3. การแปลงโมเดลเพื่อนำไปใช้งานจริง (Model Conversion & Export)
* เพื่อให้สามารถนำโมเดลไปใช้งานบนอุปกรณ์ปลายทาง (Edge Devices) เช่น อุปกรณ์เคลื่อนที่หรือเว็บเบราว์เซอร์ได้อย่างมีประสิทธิภาพ ระบบจึงรองรับการส่งออกโมเดลเป็น 2 รูปแบบย่อย:
  1. **ONNX Format:** แปลงไฟล์จาก PyTorch (`.pth`) ไปยังรูปแบบตัวกลาง ONNX (`action_model.onnx`) เพื่อนำไปรันบน Runtime อื่นๆ
  2. **TensorFlow Lite (TFLite) Format:** แปลงโมเดลต่อจาก ONNX ไปเป็นรูปแบบ TFLite โดยใช้เครื่องมือ `onnx2tf` เพื่อนำโมเดลไปใช้งานบนแอปพลิเคชันฝั่งอุปกรณ์เคลื่อนที่หรือหน้าเว็บ โดยจัดเก็บไว้ในโฟลเดอร์ `tflite_output/` ซึ่งรองรับทั้งระดับความแม่นยำ Float16 และ Float32

### 4. การทำนายผลสดเรียลไทม์ (Real-time Inference)
* พัฒนาระบบแสดงผลสดผ่านกล้องเว็บแคม โดยตรวจจับข้อต่อมือผ่านกล้องและสร้างคิวข้อมูล (Queue Buffer) ขนาด 30 เฟรมล่าสุดเพื่อป้อนเข้าสู่โมเดล
* **ระบบป้องกันความผิดพลาด (Noise Reduction System):**
  * **Hand Checking:** จะทำนายคลาสก็ต่อเมื่อมีการยกมือขึ้นมาหน้ากล้องอย่างแท้จริง (พิกัดมือซ้ายหรือขวาต้องไม่เป็น 0 ทั้งหมด) หากไม่มีมือจะทำการล้างบัฟเฟอร์การทำนายทันที
  * **Confidence Threshold:** จำกัดความมั่นใจในการทำนายขั้นต่ำไว้ที่ 90% (`threshold = 0.90`) เพื่อความถูกต้องแม่นยำ
  * **Frame Stability Check:** ผลการทำนายต้องมีความเสถียรติดกันอย่างน้อย 12 เฟรมขึ้นไป จึงจะยอมรับให้เป็นคำศัพท์ในประโยค
* **การแสดงผลข้อความภาษาไทย (Thai Text Display):** พัฒนาระบบแปลงพิกเซลภาพเพื่อเขียนภาษาไทยลงบน OpenCV Frame ได้โดยตรงโดยใช้ Pillow และฟอนต์ Tahoma (`tahoma.ttf`) เพื่อให้อ่านผลการทำนายบนหน้าจอได้ง่ายขึ้น

  * [Pillow / PIL](https://python-pillow.org/) (ช่วยประมวลผลฟอนต์ภาษาไทย Tahoma เพื่อแสดงผลลัพธ์บนกล้อง)

## 🚀 ขั้นตอนการเริ่มใช้งาน (Usage Instructions)

### 1. ติดตั้ง Dependencies ที่จำเป็น
ติดตั้งโมดูลที่เกี่ยวข้องผ่าน PowerShell หรือ Command Prompt:
```bash
pip install opencv-python mediapipe numpy torch torchvision scikit-learn pillow onnx onnx2tf
```

### 2. การเก็บรวบรวมข้อมูลใหม่ (Optional)
หากต้องการเก็บข้อมูลท่าทางเพิ่มเติม ให้เปิดไฟล์ `collect_data.py` แล้วแก้ไขตัวแปร `LABEL` เป็นชื่อคลาสที่ต้องการ จากนั้นเรียกใช้งาน:
```bash
python collect_data.py
```
* **วิธีควบคุม:** 
  * กด `S` เพื่อเริ่มโหมดเก็บข้อมูลแบบต่อเนื่อง (ระบบจะคอยจับเวลา พัก 1.5 วินาที แล้วเก็บข้อมูล 30 เฟรม วนจนครบ 100 ตัวอย่าง)
  * กด `S` อีกครั้งเพื่อหยุดบันทึกชั่วคราว
  * กด `Q` เพื่อออกจากโปรแกรมเก็บข้อมูล

### 3. การฝึกสอนโมเดล (Model Training)
หลังจากเตรียมโฟลเดอร์และไฟล์ข้อมูล `.npy` ในโฟลเดอร์ `sequences` เรียบร้อยแล้ว ให้รันเพื่อเริ่มฝึกสอนโมเดล:
```bash
python train_model.py
```
* ระบบจะทำการโหลดข้อมูลทั้งหมด, แสดงชื่อคำศัพท์ที่ตรวจพบ, เทรนโมเดลเป็นจำนวน 50 Epochs, แสดงความถูกต้อง (Accuracy) และบันทึกผลลัพธ์ลงเป็นไฟล์ `action_model.pth` และ `label_encoder.pkl`

### 4. การส่งออกโมเดลไปยัง ONNX และ TFLite
รันสคริปต์นี้เพื่อทำโมเดลให้มีขนาดเล็กลงและรองรับแพลตฟอร์มอื่น:
```bash
python export_tflite_pth.py
```
* ไฟล์ผลลัพธ์จะไปอยู่ที่โฟลเดอร์ `tflite_output/`

### 5. การทดสอบรันระบบจดจำสัญลักษณ์มือสด
เปิดกล้องเว็บแคมเพื่อเริ่มการทำนายสัญลักษณ์มือในทันที:
```bash
python realtime_predict.py
```
* **วิธีควบคุมหน้าต่างแสดงผล:**
  * ยกมือขึ้นมาหน้ากล้องและแสดงท่าทางตามที่เทรนไว้ ระบบจะทำนายคลาสพร้อมแสดงความมั่นใจ (Confidence %)
  * หากรักษาระดับความมั่นใจได้คงที่ คำศัพท์จะถูกเขียนสะสมไว้ด้านล่างเป็นประโยค
  * กด `Backspace` เพื่อลบคำศัพท์คำล่าสุดออกจากประโยค
  * กด `C` เพื่อล้างหน้าจอและข้อความประโยคใหม่ทั้งหมด
  * กด `Q` เพื่อปิดการทำงาน
